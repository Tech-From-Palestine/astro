# Electronics Astro — منصة المتجر والخدمات التقنية

موقع متكامل مبني بـ **React (Vite)** للواجهة، و **Express** للخادم، و **MongoDB Atlas** لقاعدة البيانات، حسب وثيقة متطلبات Electronics Astro.

## ما الذي يتضمنه الموقع؟

| القسم | المحتوى |
|---|---|
| الرئيسية | المنتجات المميزة، العروض، التصنيفات الـ15، الخدمات، منتجات Astro، المركز التقني |
| المتجر | بحث، تصفية حسب التصنيف/السعر/التوفر/العروض، ترتيب، صفحة منتج بمواصفات فنية ومنتجات ذات صلة |
| الخدمات | الخدمات الهندسية مع نموذج طلب لكل خدمة، وطلب عرض سعر للكميات/المنتجات المخصصة |
| المشاريع والحلول | استعراض المشاريع المنفذة والمنتجات المستخدمة فيها |
| المركز التقني | مقالات، شروحات، مشاريع تعليمية، مصادر — مرتبطة بالمنتجات |
| حسابي | البيانات الشخصية والعنوان، الطلبات وتتبعها والفاتورة، المفضلة، طلبات الخدمات |
| السلة وإتمام الطلب | إدارة الكميات، كوبونات الخصم، طرق توصيل وتكلفتها، طرق دفع متعددة، رقم طلب ورقم فاتورة، تتبع الطلب للزوار |
| من نحن / تواصل معنا / السياسات | الرؤية والرسالة والأهداف والفئات المستهدفة، نموذج تواصل، الشحن والاسترجاع والخصوصية والشروط |
| لوحة التحكم `/admin` | المؤشرات، الطلبات والمدفوعات والاستردادات، المنتجات والتصنيفات، المخزون وتنبيهاته، الكوبونات، العملاء والرسائل، طلبات الخدمات، المحتوى، التقارير المالية، المصاريف، المستخدمون والصلاحيات، إعدادات الموقع |

**الإدارة المالية:** المبيعات والإيرادات، تكلفة البضاعة (من حقل التكلفة لكل منتج)، المصاريف، الربح الإجمالي والصافي وهوامش الربح، المدفوعات والاستردادات، الفواتير (طباعة/حفظ PDF)، المبالغ المستحقة، تقرير شهري وأكثر المنتجات ربحاً، وتصدير CSV.

**الصلاحيات:** `admin` يملك كل شيء، `staff` يصل فقط للأقسام المحددة له (المنتجات، الطلبات، العملاء، العروض، المحتوى، المالية، التقارير، المستخدمون، الإعدادات).

## التشغيل خطوة بخطوة

### 1) إنشاء قاعدة البيانات على MongoDB Atlas
1. ادخل إلى https://cloud.mongodb.com وأنشئ Cluster مجاني (M0).
2. من **Database Access** أنشئ مستخدماً وكلمة مرور.
3. من **Network Access** أضف عنوان IP الخاص بك (أو `0.0.0.0/0` للتجربة).
4. من **Connect → Drivers** انسخ رابط الاتصال، وأضف اسم القاعدة `astro` قبل علامة `?`:
   `mongodb+srv://USER:PASS@cluster0.xxxx.mongodb.net/astro?retryWrites=true&w=majority`

### 2) إعداد الخادم
```bash
cd server
cp .env.example .env      # ثم عدّل MONGODB_URI و JWT_SECRET
npm install
npm run seed              # يضيف التصنيفات والمنتجات والخدمات والمحتوى وحساب المدير
# أو: npm run seed -- --demo   لإضافة طلبات ومصاريف تجريبية لتجربة التقارير المالية
npm run dev               # http://localhost:5000
```

### 3) تشغيل الواجهة
```bash
cd client
npm install
npm run dev               # http://localhost:5173
```

### 4) الدخول للوحة التحكم
- البريد: `admin@astro.ps` — كلمة المرور: `Admin@12345` (أو ما وضعته في `.env`)
- **غيّر كلمة المرور فوراً** من صفحة حسابي.
- مع `--demo` يوجد أيضاً عميل تجريبي: `customer@astro.ps` / `Customer@123`

> ⚠️ أمر `seed` يحذف المنتجات والتصنيفات والمحتوى الحالي ويعيد إنشاءها. استخدمه مرة واحدة في البداية فقط.

## النشر (Production)
```bash
cd client && npm run build      # يبني الواجهة إلى client/dist
cd ../server && npm start       # الخادم يقدّم الواجهة والـ API من نفس المنفذ
```
يمكن النشر على Render / Railway / VPS. اضبط متغيرات البيئة `MONGODB_URI`, `JWT_SECRET`, `PORT`, `CLIENT_URL`.
إذا نشرت الواجهة منفصلة (Vercel/Netlify) ضع `VITE_API_URL=https://your-api.com` في `client/.env`.

## هيكل المشروع
```
server/src
  models/      User, Product, Category, Order, Coupon, Service, Request, Article, Project, Expense, Message, Settings
  routes/      auth, products, categories, orders, coupons, users, admin (stats/finance/expenses), settings, requests/contact, crud (عام)
  middleware/  auth (JWT + صلاحيات), error
  seed.js      البيانات الأولية (seedData.js)
client/src
  pages/       صفحات الموقع العامة والحساب
  admin/       لوحة التحكم (ResourceManager عام لإدارة المحتوى)
  context/     Auth, Cart, Settings
```

## تطويرات مقترحة لاحقاً
- ربط بوابة دفع إلكتروني (طريقة `card` معدّة ومعطلة في الإعدادات).
- رفع الصور إلى خدمة تخزين (Cloudinary/S3) بدل روابط الصور.
- إشعارات بريد/واتساب عند تغيير حالة الطلب.
- ربط مع برنامج محاسبي، ونظام عروض أسعار تلقائي للكميات الكبيرة.
